# v1.0.6 - Windows Installer Repair / 安装修复

## 中文

- 安装器及卸载器主动申请管理员权限，兼容旧版以当前用户方式安装在
  Program Files 中的情况；应用本体仍以普通用户权限运行。
- 在关闭应用、卸载旧版之前检查安装目录写入权限；权限不足会明确提示，
  不再进入旧版卸载流程后反复重试。
- 默认临时目录不足 2 GB 时，尝试在安装目录所在磁盘创建独立、受限的
  临时目录，并以原参数重新运行本次安装。仅设置安装进程的环境变量，
  不修改系统 TEMP/TMP，完成后清理本次目录。
- 保留托盘退出与任务保护，不强杀进程，不删除配置、会话及平台授权。

安装时请完成 Windows 的管理员确认。若取消提权或没有可写的足够空间，
安装不会继续。安装包仍未代码签名，请核对来源和校验值。

## English

- Setup and Uninstall request administrator permission for legacy per-user
  installations in protected Program Files folders. The app remains asInvoker.
- Write access is checked before closing applications or uninstalling an older
  version. Permission failures produce a specific message and exit code 40.
- If the default temporary drive has less than 2 GB available, Setup tries a
  unique restricted directory on the installation drive and relaunches with
  the original parameters. Only its process environment changes; system
  TEMP/TMP settings remain unchanged. Its staging directory is then removed.
- Graceful tray quit and active-job protection remain in place. No forced
  termination or deletion of user configuration, conversations or authorization.

Accept the Windows administrator prompt to install. Cancellation or insufficient
writable temporary space prevents installation. Windows packages remain unsigned;
verify the source and checksums.
