# v1.0.3 · 安装与退出修复 / Installer And Shutdown Fix

## 下载 / Download

[Windows 安装版与免安装版 / Installer and portable](https://github.com/JKZeng-cell/codex-chat-bridge-manager/releases/tag/v1.0.3)

## 修复内容

- 安装器改为精确检查目标应用与该目录下的内置工具，避免把安装器自身或相似目录下的程序误判为应用仍在运行。
- 请求应用正常关闭，不按名称或目录前缀批量强杀进程。任务未完成或窗口仍待确认时停止安装，保留配置与历史。
- 应用退出改为直接读取内部任务状态，不再依赖一次完整的本地 HTTP 概览请求。
- 空闲状态下的清理增加超时，避免清理异常造成窗口关闭后仍有不可见的后台进程。无法确认任务状态时，不强制退出。
- 退出时释放管理页轮询与未完成请求占用的 HTTP 连接，修复空闲应用偶发无法完成关闭的问题。
- 从应用安装目录内启动升级包时，明确提示先移到下载目录，避免安装包自身占用目标文件。

## 更新步骤

1. 取消旧安装器，等待机器人任务或工具更新完成，并退出全部旧版桌面实例。
2. 从本发布页下载新安装包，放在下载目录中运行，不要直接放进旧应用安装目录。
3. 保留 `%APPDATA%/CodexChatBridgeManager` 即可保留桌面配置与会话。

若旧版仍在运行，请先从菜单「应用 → 退出」结束它。若旧版曾以管理员权限运行，需要在同一权限级别退出；不要强制结束尚有任务的应用。

## English

- Scope installer detection to the exact application executable and its bundled tools, not every process whose path shares an installation-directory prefix.
- Request a normal window close; do not force-kill all processes by name. Active tasks or pending confirmation stop installation without deleting settings or history.
- Inspect in-process task state during desktop shutdown instead of requesting a full HTTP overview. Bound idle cleanup so failures cannot leave an invisible process indefinitely.
- Close management-page polling and incomplete HTTP connections during shutdown, fixing intermittent idle-exit stalls.
- Reject an installer launched inside its target installation directory with a clear instruction to move it to Downloads first.
- Cancel the old installer, finish active tasks, quit the desktop app, then run the new installer from Downloads. Keep the application-data directory to retain settings.

Windows x64 packages remain unsigned (`NotSigned`). Verify SHA-256 checksums before installation.
