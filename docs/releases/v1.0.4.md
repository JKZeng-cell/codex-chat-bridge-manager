## 操作方式

- 最小化或关闭窗口：隐藏到系统托盘，机器人服务继续运行。
- 点击或双击托盘图标：恢复同一个工作台窗口，不启动第二套服务。
- 右键托盘：打开工作台、最小化到托盘或退出。
- 需要停止服务：使用托盘「退出」或「应用 → 退出」，不再通过窗口关闭按钮退出。
- 有任务或工具更新时，退出仍会被阻止，并恢复窗口显示提示，不强制结束任务。
- 系统托盘无法创建时，会提示用户；关闭窗口恢复为正常退出，避免无法找回隐藏窗口。

托盘模式不是 Windows 系统服务，不会自动开启开机启动；休眠、关机或注销仍会影响后台运行。

## 安装兼容

安装器识别支持托盘的版本，通过同目录应用的单实例通信请求正常退出，
不再把窗口隐藏误认为进程关闭。旧版本仍使用原来的正常窗口关闭方式。
已有任务仍会阻止安装继续，不按名称批量结束进程，不删除配置与授权。

## English

Minimize or close the window to keep services running in the system tray.
Click or double-click the tray icon to restore the existing window; use the tray
Exit action or Application → Exit to stop services. Busy tasks still block exit
and restore the window with a warning. If tray creation fails, closing the window
falls back to normal shutdown.

The installer uses protected single-instance quit IPC for tray-capable versions
and retains normal window close for legacy versions. No force-kill or deletion
of configuration/history is introduced.

Windows packages remain unsigned. See [validation scope](../VALIDATION.md).
