Node.js installation is required. Sign in through Application → Codex Login.

## 更新内容 / What's New

- 系统页新增服务运行状态：运行时长、在线机器人、执行中与排队任务。
- 新增 Codex 状态卡：CLI 版本、登录方式和检测时间，支持手动重新检测。
- 服务连接中断时标记信息过期；区分本地登录状态与模型网络连通性。
- 页脚增加 Powered by JKZeng；完善中英文 README 与语言切换入口。
- 宣传海报加入飞书、企业微信、微信和钉钉官方图标；功能介绍拆成 4 张 1200×1600 图片，文案聚焦使用场景。

- System health now shows uptime, online bots, active tasks, and queued tasks.
- A dedicated Codex card shows CLI version, login method, check time, and a manual recheck action.
- Disconnected management status is marked stale. Local CLI login is not reported as verified model connectivity.
- Added the Powered by JKZeng footer and clearer bilingual README navigation.
- Updated social assets with official platform artwork and four independent 1200×1600 feature cards.

## 使用说明 / Notes

- 桌面版继续使用 `%APPDATA%/CodexChatBridgeManager`，默认仅监听本机 3211 端口。升级不会导入网页工作台的机器人、会话或飞书 CLI 授权目录。
- Windows 应用包未签名（`NotSigned`），可能出现未知发布者提示。请仅从本仓库下载，并核对 SHA-256；临时磁盘建议保留至少 2 GB 空间。
- 安装更新前请结束正在运行的任务并退出旧桌面应用；保留应用数据目录即可继续使用已有配置。
- 独立第三方项目，非 OpenAI 或聊天平台官方产品。平台可用性受账号权限、企业策略与地区政策影响，自动化测试不代表四个平台全部完成实机授权验收。
- 配图为演示数据；Codex 已登录不等于模型权限、额度或网络连通已经验证。

Desktop data remains in `%APPDATA%/CodexChatBridgeManager`, using loopback port 3211.
Existing web-manager data is not imported. Quit the old app after active jobs
finish before installing. Packages are unsigned; verify checksums and allow at
least 2 GB of temporary disk space. This is an independent third-party project,
not an official product. Platform availability depends on account and organization
policies; automated tests are not live authorization certification for all four platforms.
